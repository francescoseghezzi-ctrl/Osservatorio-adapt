# Roadmap (priority ordered)

1. Make the historical-series builder robust on mobile; verify controls, labels, legends and exports.
2. Improve accessibility of all chart controls (keyboard navigation and screen reader labels).
3. Improve handling of incompatible units, missing values and indexed comparisons.
4. Make year selectors and displayed headline KPIs consistent throughout the app.
5. Improve chart exports so SVG files include metadata and source labels.
6. Improve dense tables on smartphones without breaking the full data view.
7. Build visible source/methodology links at chart-level, without inventing new sources.
8. Prepare an independent data-import pipeline, **but do not populate new official values without verified sources and explicit approval**.

Every cycle should select just one unmet need. No fictitious data. User review is required before merge.
